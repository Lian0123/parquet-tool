01 / GET STARTED

準備して、始めましょう。

Node.js 18 以降が必要です。使用例はローカルのターミナルで実行してください。

01

パッケージをインストール

作業フォルダーを作成し、npm パッケージをインストールします。

mkdir parquet-demo
cd parquet-demo
npm init -y
npm install parquet-tool

インストール時にネイティブモジュールのビルドが必要な場合は、インストールガイドを参照し、CMake と C++ ツールチェーンを準備してください。

02

サンプルデータを準備

ファイルをダウンロードして作業フォルダーに置きます。

↓ input.json 3 行↓ input.csv 同じデータ

列：id、name、active。データは架空のサンプルです。

03

使用例を選択

CLI コマンドはターミナルに貼り付けて実行します。Node.js コードは example.cjs として保存し、実行してください。

node example.cjs

使用例はローカルの Node.js で動作します。また、ブラウザー変換ツールを使えば、パッケージをインストールせずに CSV・JSON・Parquet を変換できます。

QUESTIONS & ANSWERS

Parquet 変換のよくある質問

parquet-tool とは何ですか？

parquet-tool は Node.js 18 以降に対応する TypeScript ライブラリと CLI です。ブラウザー版も同じ C++ Parquet コアを WebAssembly で使用し、12 の使用例を提供します。

ブラウザー版ではどの形式を変換できますか？

ブラウザー版は CSV・JSON・フラットな Parquet の全 6 方向の変換に対応します。Arrow IPC と XML は Node.js / CLI の使用例をご利用ください。

ブラウザー変換ツールに Node.js は必要ですか？

不要です。JavaScript モジュールと Web Worker に対応する最新のブラウザーで開いてください。Node.js / CLI の使用例には、ローカルの Node.js 18 以降と parquet-tool が必要です。

QUESTIONS & ANSWERS

Parquet 変換のよくある質問

CSV を Parquet に変換するには？

ヘッダー付き UTF-8 CSV を選択・ドロップし、プレビューを確認して Parquet に変換・ダウンロードします。本プロジェクトのコアで無圧縮 PLAIN 形式を出力します。

Parquet を JSON または CSV に変換するには？

フラットな Parquet ファイルを選び、プレビュー後に JSON または CSV を選択して変換・ダウンロードします。CSV はカンマ・セミコロン・Tab、JSON はオブジェクト配列で出力します。

ファイルはサーバーに送信されますか？

送信されません。読み込み・プレビュー・変換はブラウザーの Web Worker 内で実行します。エンジンはサイトとともに配信され、ファイルを外部の変換サービスへ送りません。

容量の上限はありますか？

1 ファイル 20 MiB、100,000 行、200 列、2,000,000 セルまでです。フラットな表のみ対応し、入れ子・バイナリ列は未対応です。圧縮ファイルの展開には追加メモリを使います。処理は中止できます。

大きな整数・欠損値・混合型はどう扱われますか？

INT64 は JSON / CSV で十進数文字列になります。安全な精度を超える JSON 数値には引用符付き文字列を使用してください。空欄や欠けた項目は null、混合型と日付は文字列になります。

現在の CLI と Parquet ファイルを直接交換できますか？

はい。ブラウザーと Node.js / CLI は本プロジェクトの C++ コアを共有し、無圧縮 PLAIN データページ v1 に対応します。旧版の schema も読み取れます。圧縮・入れ子・その他の logical type は未対応で、metadata 全体は保持しません。

ファイルはサーバーに送信されません。変換コードはサイトと一緒に配信され、処理に外部サービスを使いません。

ローカル版と共通のコア

ブラウザー版は WebAssembly を通じて本プロジェクトの C++ コアを使用し、Node.js / CLI と Parquet 実装を共有します。無圧縮・PLAIN・データページ v1 に対応し、それ以外の圧縮・エンコーディングは明示的に拒否します。

対応範囲

ヘッダー付き UTF-8 CSV、JSON オブジェクト配列または { rows: [...] }、フラットな Parquet に対応します。JSON の schema は適用せず、データから型を推定します。

型が混在する列は文字列になります。日付や巨大な JSON 整数は文字列で保存してください。入れ子・バイナリ列は未対応です。上限は 200 列・2,000,000 セルです。

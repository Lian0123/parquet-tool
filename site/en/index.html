01 / GET STARTED

Set up, then get started.

Requires Node.js 18 or later. Run these examples in your local terminal.

01

Install the package

Create a working directory and install the npm package.

mkdir parquet-demo
cd parquet-demo
npm init -y
npm install parquet-tool

If installation requires compiling the native addon, follow the installation guide to prepare CMake and a C++ toolchain.

QUESTIONS & ANSWERS

Parquet conversion FAQ

What is parquet-tool?

parquet-tool is a TypeScript library and CLI for Node.js 18+. The browser compiles the same C++ Parquet core to WebAssembly. This site also provides 12 reading, writing, conversion and processing examples.

Which formats can the browser convert?

The browser converts between CSV, JSON and flat Parquet in all six directions. Use the Node.js / CLI examples for Arrow IPC and XML.

Do I need Node.js for the browser converter?

No. Open the converter in a modern browser with JavaScript modules and Web Workers. The Node.js and CLI recipes require Node.js 18+ and parquet-tool installed locally.

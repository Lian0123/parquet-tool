QUESTIONS & ANSWERS

Parquet 轉換常見問題

如何將 CSV 轉成 Parquet？

選擇或拖入含標題列的 UTF-8 CSV，確認資料預覽，將輸出格式設為 Parquet，再按「開始轉換」與「下載檔案」。可選擇 Snappy 或不壓縮。

如何將 Parquet 轉成 JSON 或 CSV？

選擇平面 Parquet 檔案，預覽資料後，將輸出格式設為 JSON 或 CSV，再開始轉換並下載。CSV 可選擇逗號、分號或 Tab 分隔；JSON 輸出為物件陣列。

檔案會上傳到伺服器嗎？

不會。檔案讀取、資料預覽與轉換都在你的瀏覽器 Web Worker 中執行。轉換引擎隨網站載入，不透過第三方轉換服務傳送檔案。

支援多大的檔案？

單檔最多 20 MiB，最多 100,000 列、200 欄與 2,000,000 個儲存格。目前支援平面資料表，暫不支援巢狀或二進位欄位。壓縮檔案解碼後會使用更多記憶體，可隨時取消處理。

大整數、空值與混合型別如何處理？

Parquet INT64 在 JSON／CSV 輸出為十進位字串。JSON 超出安全精度的數值會被拒絕，請改用帶引號的字串。CSV 空欄位與 JSON 缺少的欄位轉為 null；混合型別欄位以文字保存，日期轉為 ISO 文字。

網頁版的 Parquet 可以直接與目前 CLI 互用嗎？

目前 C++ CLI 與網頁使用的標準 Parquet 引擎存在互通限制，請透過 CSV 或 JSON 在兩者之間交換資料。網頁版不保留原檔的完整 schema、metadata 或所有 logical types。

支援範圍

支援 UTF-8 CSV（含標題列）、JSON 物件陣列或 { rows: [...] }、平面 Parquet。JSON 的 schema 區塊不會套用；型別由資料辨識。

混合型別欄位以文字保存；日期轉成 ISO 文字，超大整數請在 JSON 使用字串。暫不支援巢狀或二進位欄位。最多 200 欄、2,000,000 個儲存格。

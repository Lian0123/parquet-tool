01 / GET STARTED

先準備好，再動手。

需要 Node.js 18 以上版本。範例請在本機終端機執行。

01

安裝工具

建立工作資料夾，安裝 npm 套件。

mkdir parquet-demo
cd parquet-demo
npm init -y
npm install parquet-tool

若安裝時需要編譯原生模組，請先依安裝文件準備 CMake 與 C++ 工具鏈。

02

準備範例資料

下載後將檔案放進剛建立的工作資料夾。

↓ input.json 3 筆資料↓ input.csv 相同內容

欄位：id、name、active。資料為虛構示例。

03

挑一個範例開始

CLI 指令直接貼到終端機；Node.js 程式儲存為 example.cjs 後執行。

node example.cjs

這是靜態範例網站。檔案處理在你的本機 Node.js 執行，頁面不會上傳或轉換檔案。

基本讀寫# 範例連結

建立第一個 Parquet 檔案

使用明確的 schema，將 input.json 寫成 data.parquet。

準備：先下載 input.json 到工作資料夾。

npx parquet-tool write data.parquet -i input.json -s "id:INT32,name:STRING,active:BOOLEAN"
執行後

產生包含 3 筆資料的 data.parquet。

在工作資料夾的終端機執行。查看原始碼 ↗

每個範例皆列出前置需求。新增資料會修改既有檔案；需要重跑時，可先重新執行「建立檔案」。

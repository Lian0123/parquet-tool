01 / GET STARTED

先準備好，再動手。

需要 Node.js 18 以上版本。範例請在本機終端機執行。

01

安裝工具

建立工作資料夾，安裝 npm 套件。

mkdir parquet-demo
cd parquet-demo
npm init -y
npm install parquet-tool

若安裝時需要編譯原生模組，請先依安裝文件準備 CMake 與 C++ 工具鏈。

QUESTIONS & ANSWERS

Parquet 轉換常見問題

parquet-tool 是什麼？

parquet-tool 是 Node.js 18 以上可用的 TypeScript 函式庫與 CLI，核心讀寫使用 C++ 原生模組。這個網站另提供獨立的瀏覽器轉換工具，以及 12 個讀寫、轉換與資料處理範例。

網頁版可以轉換哪些格式？

網頁版支援 CSV、JSON、平面 Parquet 三種格式互轉，共六個方向。Arrow IPC 與 XML 轉換請使用 Node.js／CLI 範例。

使用網頁轉換工具需要安裝 Node.js 嗎？

不需要。使用支援 JavaScript 模組與 Web Worker 的現代瀏覽器，開啟轉換頁即可。教學中的 Node.js 與 CLI 程式碼則需要在本機安裝 Node.js 18 以上及 parquet-tool。
